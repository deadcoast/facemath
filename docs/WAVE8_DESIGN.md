# Wave 08 · Acquisition support travels with the source

## Priority decision

This extends the actual attached Wave 07 ZIP, not a reconstructed project. Its baseline suite was executed before development. Native MediaPipe was not installed; DNS lookups for the package/model hosts failed and an actual model-download tool attempt failed. The live-observer/independent-human-reference gate remains open. No synthetic result is relabeled live inference.

Wave 07 made acquisition-category failures visible but deployed a pooled radius. Wave 08 closes that operational/numerical gap: a prespecified category can qualify a query only through its own retained calibration-group evidence. Unsupported conditions cannot inherit a pooled radius merely because their domain strings match.

## One instrument, no parallel analyzer

`RoutingPolicy` freezes the categories, their acquisition definition and a minimum calibration-group policy. `StratumRadius` retains the complete category score inventory and derives its rank, radius and reason for withholding. `StratifiedJointCalibration` preserves the single development mean/scatter and the original pooled scores. `BoundStratifiedCalibration` binds exactly two query observations and their group/lineage/category declarations.

The existing prospective runner still owns source acquisition and receipts. The existing source-coordinate evaluator still computes every raw localization error. The existing joint fit still computes mean/scatter and joint scores. `qualify` partitions calibration group maxima; it never fits on evaluation. The existing `FacialInstrument` resolves the source routes before building its canonical state and sends the two radii through the existing localization envelope and `SourceRelations` graph. Artifact writing, byte verification and numerical replay are the existing mechanisms.

The raw coordinates, perturbation covariance, selected error covariance, registration, fields and nominal geometry do not change. The arrays `localization_source_quantiles` and `intrinsic_source_quantiles` expose the two radii. An old scalar `quantile` is present only when they agree; a null legacy scalar does not mean the two-source envelope is unbounded. Explicit availability fields govern that distinction.

## Protected context

A category radius fragment is not independently loadable as a valid older localization model. The full wrapper binds the partition, shared development model and scoring recipe. Its category group/image/lineage inventories must be disjoint and exactly reconstruct the retained pooled calibration inventory. Query leakage is checked against ALL calibration categories plus development, not merely the selected category.

Related query sources cannot claim incompatible categories. Once bound, changing an image, observation, group, lineage or radius invalidates the route. Binding is not external attestation of curator honesty: an operator could start a new study with false declarations. Hashes cannot establish when a person chose a category or whether a source actually belongs to it. New declarations require a new recorded analysis; the pair workbench has no category-selection control.

The study loader rechecks routing contracts even after a lock's byte inventory has been consistently rehashed. This detects semantic contradictions, not an attacker who changes every input and every declaration coherently. Numerical replay remains stronger than byte consistency for derived results.

## Unsupported acquisition is not zero error

Missing categories, too few groups and unbounded order statistics have distinct reasons. There is no nearest-category or pooled fallback. A calibrated pair request in an unsupported category fails before canonical geometry, preserving the actual partial execution journal. A user can explicitly run nominal uncalibrated geometry; it is a different, labeled analysis, not silent fallback inside a calibrated request.

All held-out eligible groups stay in acquisition accounting. Unsupported groups contribute no successful finite delivery to the all-enrolled denominator. Coverage among supported groups is separately reported and must not be mistaken for coverage across all enrollment.

A category is not an automatic distribution-shift detector. The laboratory deliberately changes observer errors within the SAME clear acquisition label. Its failures remain visible. No thresholds, radii, category definitions or exclusions are repaired using those held-out errors.

## Executed laboratory design

The default seed is 28091, selected in source before inspecting outputs. It enrolls 32 development, 84 calibration and 38 evaluation groups, plus one prospectively excluded enrollment. Calibration counts are clear60 / degraded20 / sparse4 / unseen0. Evaluation counts are clear20 / degraded12 / sparse3 / unseen3. The last eight clear evaluation cases receive a prespecified hidden error shift. One calibration clear case and one evaluation degraded case are prescribed nondetections.

Each schematic source has known renderer coordinates and a new, fully declared scripted observer error recipe. The degraded raster receives a fixed Gaussian blur, but the imposed error distribution is scripted, NOT evidence that a real detector reacts to blur this way. Sparse/unseen are declared experimental acquisition configurations. Their role is to test support accounting, not human imaging performance.

The first batch commits seven attempts. Completion and resume test the inherited no-retry rule. Four fresh clear/degraded pairs have prespecified mouth expansions 0,4,8,12px. Query selection is not based on whether the resulting bounds contain their known reference gaps. The laboratory reports any violation rather than selecting successful queries. A separate admitted-set control uses unequal radii and retains 1,024 paired shape draws.

## Faults and corrections

1. The first integrated model reload failed because JSON converts nested tuples to lists. Direct dictionary roundtrips had passed. Canonical-content comparison now validates exact serialized meaning, with a regression through JSON bytes. It does not drop unknown-field/derived-value checks.
2. The legacy scalar-radius convention could not represent two finite unequal radii. Per-source radii now propagate explicitly through support calculations, refitted bounds, available-state serialization, ellipse rendering and coherent-mode displays. A null legacy scalar is not silently converted into zero.
3. Mixed-radius tests reject boolean/string values and numerical overflow rather than coercing or exporting invalid bounds.
4. Two initial integration-test assertions used guessed field/message names; they were corrected to `calibration_bound_state` and the actual cross-stratum error. No numerical assertion was relaxed.
5. Routing reports distinguish no deployable radius from zero, and omit a misleading aggregate iid-binomial interval for a heterogeneous mixture with abstentions.

## Report and execution boundaries

The category workbench displays retained group scores, selected ranks and unsupported reasons, with exact CSV export. The pair report displays immutable source routes; all fields originate from saved evidence. Source-specific ellipses and full16 modes use their own q, not a common scalar. UI controls change displays only.

Browser checks attempt local file navigation first. Where that is administratively blocked, the actual emitted HTML is loaded in memory and the limitation recorded. Source/evidence paths are checked on disk separately. The report makes no remote requests; it is not a network sandbox for optional third-party inference.

Source, installed-wheel and extracted-archive tests establish their executed numerical/software contracts, not human accuracy, a universal similarity percentage, or completion of the historical 0–180 mathematics inventory. Exact replay uses captured observations and the same code/numerical runtime. It does not rerun a detector or retrieve historical neural telemetry.

## Next empirical work

Determine usable categories and group composition on development data; freeze them before calibration and evaluation. Check both delivered availability and held-out coverage, including hidden within-category shifts. Automatic acquisition-condition checks and supported contour/visibility evidence are subsequent priorities. More interval tightening without real references is not a substitute for that study.
