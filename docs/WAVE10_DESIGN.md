# Wave 10 · Consolidate the instrument, separate finite results from empirical acceptance

## Parent and priority

The actual Wave 09 archive was verified against SHA-256 `690568754812a5d34fff61cb41be634617d2078a89caf0fcfd1ec7c758baef1f`, extracted and installed. Its full baseline reproduced 790 passes and one live-observer skip. The archive was not recreated from a prose description.

The main unmet empirical gate remains native observer execution against independent real source-coordinate annotations. A real package/model acquisition attempt again failed in this environment. The milestone therefore does not claim human performance. It makes the operational route to that study usable and prevents a failed held-out study from silently authorizing the new optional deployed path.

## Architectural ownership

- `workspace.py` snapshots source rasters and wraps the existing blank annotation UI, ReferenceAnnotation, study freezer and OS writer lock. It does not supply landmarks or a new observer.
- `admission.py` consumes the existing selected model's scored rows, frozen categories and full evaluation inventory. It fits no model or geometric score.
- `deployment.py` admits only a replayed complete qualification and passes its unchanged error model into FacialInstrument. It carries original raw study bytes into the resulting pair rather than adding an unauditable approval string.
- `native_check.py` invokes the existing pinned NativeExecutor/worker when preflight succeeds. Missing prerequisites are not counted as observations. It does not download files implicitly.
- `readout.py` renders existing evidence. Percentages are explicit inventory fractions; no resemblance probability is created.
- `milestone_lab.py` runs independently frozen positive/negative synthetic workflow controls through those real components. It is not a second production pipeline.

The instrument's image-bound observations, original coordinates, registration, regional masks, deformation fields, covariance models, source radii and intrinsic relation graph remain the same. A successful acceptance check does not rewrite geometry. Existing research calibrations remain usable, with their empirical status explicitly absent.

## Reference workspace lifecycle

`prepare` validates the declared inventory and copies stored-raster pixels. Each included source/rater gets a blank standalone workbench. The tool creates no human labels. `import` validates exact source binding, assigned rater and provenance. A duplicate import is idempotent. A changed annotation creates a new immutable reference file and receipt pointing to the previous selected version.

`freeze` runs under the same writer lock as intake. It selects the latest explicit annotation per case/rater and embeds every original receipt and reference revision in the study lock. Both the freezer and later loader check history continuity, supersession, source binding and agreement between selected revisions and actual frozen references.

A crash after publishing a label but before committing its receipt leaves an explicit orphan. Status refuses to promote it. Preserve that directory; perform documented operator review or create a new workspace rather than silently deleting forensic data. The current release intentionally has no automatic orphan-repair command.

Rater IDs and `none_declared` prediction exposure are declarations, not evidence of distinct humans or provable blinding. Native empirical admission requires nonsynthetic independent-reference kinds with no declared exposure; this contract cannot prove the declaration itself.

## Empirical acceptance and source routing

The optional policy is frozen before observation and names all required measured acquisition categories. It uses complete eligible evaluation groups, retaining no-face, runtime/interruption outcomes and unsupported radii as nondelivery rather than removing them from the denominator. Exact one-sided CP lower bounds are adjusted across both endpoints and all requested categories. All requested categories must pass together.

Research model application and empirically gated application are separate invocation modes. `--qualification` requires a complete qualification bundle, exact numerical replay and an accepted policy; `--localization-calibration` remains research. The former forbids overlap with evaluation and excluded enrollment as well as development/calibration. All group context pixels participate in this check.

Finite localization coverage is not a guarantee of narrow intervals, identifiable 3D anatomy, acceptable face quality or a hidden-shift detector. Empirical acceptance is not an externally certified deployment approval and does not control adaptive repeated studies.

## Failure journals and portability

The inherited instrument already attached real partial journals to exceptions, but the CLI only printed the exception. The new CLI preserves those actual journals in a create-only sibling file. It never invents completion events or overwrites the previous failed run.

Portable qualification snapshots use deterministic ZIP metadata and bounded safe extraction. Internal arrays never use pickle loading. Loader validation rejects traversal, absolute paths, alternate-data-stream syntax, symlinks, duplicate/case-colliding names and Windows reserved device paths. Extraction requires an empty private directory.

Source/wheel/re-extracted-archive checks are separate from platform compatibility. The CI matrix provided with the release is a future execution configuration, not a claim that Windows/macOS jobs ran here. Exact historical replay still needs the original code and numerical environment; no old bundle is relabeled as a new exact replay.

## Development faults retained

The first independent CP test used a tolerance below the reference solver's absolute root tolerance: two comparisons differed by about 2.3e-13. The cross-solver tolerance was corrected to 2e-12, with additional closed-form and binomial-tail identities tested much more tightly. No inherited mathematical assertion was relaxed. Initial and final logs are retained.

The first full regression run also exposed a new readout assumption: nominal uncalibrated relation fractions are intentionally null, not a two-element bound. That broke the old demo/annotation routes. Rendering now preserves explicit unavailability rather than synthesizing zero or percentages; a new null-bound regression and the unchanged inherited routes test this correction.

Other regressions explicitly exercise annotation supersession, missing-rater/anchor support, invalid source paths, unsafe snapshots, raw-derived-report tampering, evaluation/context leakage, native preflight outcome accounting, zero native calls on refusal and exact raw-state invariance. The validation record records the actual executed outcomes, including any later development fixes.

## What is not claimed

No native landmark output or real human localization coverage was generated by the synthetic controls. The historical 0–180 section registry remains an inventory; known proxy/non-equivalent mappings are not renamed as complete mathematics. The new readout does not validate the original video's resemblance or reconstruct hidden neural telemetry.
