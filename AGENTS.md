# FACEMATH engineering handoff

The active unit of analysis is one image-bound Observation pair -> CanonicalState -> typed evidence bundle. Do not build a second alignment, reinterpret calibration radii as scores, or replace measured coordinates with fitted error-model centers.

## Before changing source

Read README and the current milestone design. Run the inherited tests from the actual package; record the parent archive digest and baseline output. Report a missing parent rather than fabricating its bytes. Keep the old mathematics audit and research inventory honest.

## Numerical contracts

Source coordinates are decoded stored-raster pixel centers, not EXIF display coordinates. Proper rotations exclude reflection. Reference eye spans remain uncertain where the reference sets are uncertain. Cross-landmark dependencies, missingness and frozen denominators survive through the shared relation graph. Samples falsify bounds; they do not define them or prove universal containment.

Development fits error models; calibration chooses radii; evaluation tests the frozen model. No retuning on evaluation outcomes. Ordinary research calibration is not empirical acceptance. `--qualification` must recompute the retained study and enforce every required category, complete group denominators and full-enrollment query/context leakage. Never detach a radius from its fitted center/scatter/protocol.

## Provenance

No synthetic observer, API fixture, availability check or model digest is live human-reference validation. Do not claim private model telemetry. Raw-state arrays, inputs and actual journals outrank plausible narrative. Hashes show consistency, not external authenticity. Never overwrite a result to repair its apparent provenance; create an explicitly distinct run.

## Required validation

Run `python -m pytest -q`. Exercise `milestone-lab`, `verify` and `replay` with the final code fingerprint. Confirm all observed-state arrays remain unchanged when adding qualification. Build a wheel, install it outside the source tree, run tests there without accidentally importing `src`, and verify package bytes. Extract the final archive and repeat validation. Record skip reasons and environment, commands, return codes and raw logs. A browser screenshot alone is not an interaction test.

Use the future roadmap to choose substantive work. The next real gate is independent real portraits and pinned native observation, not more synthetic interval tightening.
